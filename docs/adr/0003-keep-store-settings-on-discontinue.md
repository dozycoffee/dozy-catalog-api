# ADR-0003: 단종·재활성화 때 매장 설정을 바꾸지 않는다

- **상태**: 채택
- **날짜**: 2026-09-18 (소급 작성)
- **관련**: [요구사항](../requirements.md) 1.3, 2.6, 3장

## 맥락

원래 요구사항 2.6은 "단종하면 매장 개별 설정을 숨김으로 전환하고, 재활성화하면 복원한다"였다. 그런데 이렇게 구현하면 "점주가 원래 숨겼던 상품"과 "단종 때문에 숨겨진 상품"이 같은 `HIDDEN` 값이 된다. 그러면 재활성화할 때 무엇을 복원해야 하는지 알 수 없다.

## 결정

- 단종이나 재활성화 때 매장 진열 설정(`visibility`)을 바꾸지 않고 그대로 보존한다.
- 단종의 효과는 노출 판단 1단계(`Product.status != ACTIVE`면 비노출)가 낸다. 재활성화하면 보존된 점주 설정이 그대로 적용된다.
- 따라서 `ProductActivated`/`ProductDiscontinued`에 대한 Catalog 내부 반응은 없고, 외부 서비스로 전파만 한다.
- 요구사항 2.6을 이 동작에 맞게 고쳤다. 단종 전에 노출 중이던 매장은 다시 노출되고, 점주가 숨겨 둔 매장은 계속 숨김이다.

## 검토한 대안

- **단종 시 숨김으로 바꾸고 재활성화 시 복원(원래 요구사항)**: 점주가 숨겼던 상품까지 다시 노출된다.
- **"단종 때문에 숨김" 표시 필드를 따로 둠**: 구분은 되지만 상태가 하나 늘고, 단종·재활성화 때마다 매장 수만큼 row를 일괄 수정해야 한다.

## 결과

- **얻는 것**: 점주의 의도가 보존되고, 단종·재활성화 때 매장 설정을 일괄 수정하지 않아도 되며, 동시성 부담도 없다.
- **감수하는 것**: 노출 여부는 매장 설정만으로 알 수 없고 항상 상품 상태와 함께 판단해야 한다(`ProductVisibilityPolicy`).
